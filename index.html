The Practitioner's Compass

— a brief decumentum for choosing the proper species —
Question I
One step, one tool?
A simple call. Reach for the Tool-User or, if knowledge is wanted, the RAG Agent.
Question II
Many topics, one entry?
Triage required. The Router shall dispatch each query to its proper specialist.
Question III
Complex task, unknown steps?
Decomposition is needed. Summon the Orchestrator to plan, dispatch, and synthesise.
Question IV
Quality matters above all?
Add a critic. The Reflection Loop iterates until the work is fit for the field.

Glossarium Strategiarum

Strategema I

Chain of Thought

The agent reasons aloud, step by step, before answering. Trades latency for accuracy on multi-step problems.

Strategema II

ReAct

Interleaves reasoning and action: think, call a tool, observe, think again. The foundational pattern.

Strategema III

Plan-and-Execute

One pass to draft a plan, a second to execute it. Cheaper than ReAct for long tasks; brittle if the plan is wrong.

Strategema IV

Reflection

A second model — or the same one in another role — critiques and revises the output until a quality bar is met.

Strategema V

Tool Use

The agent calls external functions: search, code, databases, APIs. Tools extend cognition into the world.

Strategema VI

Memory

Short-term (the conversation), long-term (vector stores, knowledge graphs). Without it, every meeting is the first.

Strategema VII

Human-in-the-Loop

The agent pauses for approval at consequential steps. Essential when actions are costly or irreversible.

Strategema VIII

Guardrails

Filters on input and output: policy, schema, safety. The fence between the experiment and the field.

Strategema IX

Handoff

One agent transfers control — and context — to another. The mechanism that turns a solitary agent into a coetus.
